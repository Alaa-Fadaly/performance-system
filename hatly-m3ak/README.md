# 🛵 هاتلى معاك

تطبيق ويب على Google Apps Script: الموظفين بيطلبوا فطار (فول وطعمية) وحاجات سوبرماركت، ومسئول التوصيل بيشوف الأوردر المجمع (كل صنف قدامه صاحبه) وبعد ما يجيبه بيشوف حساب كل واحد + الدور والمكتب.

## التركيب
1. افتح [script.google.com](https://script.google.com) ← **New project**.
2. انسخ `Code.gs` في ملف `Code.gs`، وأنشئ ملف HTML اسمه `index` وانسخ فيه `index.html`.
3. (اختياري) Project Settings ← Show `appsscript.json` ← انسخ محتوى `appsscript.json`.
4. **Deploy ← New deployment ← Web app**: Execute as *Me*، Who has access *Anyone*. ابعت اللينك للموظفين.
5. أول فتح بيعمل Google Sheet اسمها «هاتلى معاك - البيانات» أوتوماتيك (Users / Menu / Orders / Lines) ومعاها منيو جاهز.

## قراءة الريسيت (اختياري)
عشان زر «📷 ارفع صورة ريسيت» يشتغل ضيف في Script properties: `ANTHROPIC_API_KEY` (مفتاح Claude API). لو عايز موديل تاني ضيف `CLAUDE_MODEL`. أول مرة هيطلب صلاحية الاتصال بالإنترنت (UrlFetch) وإنت بتعمل Deploy جديد.

## كود مسئول التوصيل
افتراضياً `1234`. غيّره من Project Settings ← Script properties ← `COURIER_PIN`.

## طريقة الاستخدام
- **الموظف**: يسجل اسمه والدور ورقم المكتب (مرة واحدة) ← يختار المحل والأصناف (أو صنف مكتوب بإيده) ← «ضيف للأوردر». يقدر يمسح طلبه طول ما الأوردر مفتوح.
- **تبويب الأوردر**: الموظف يشوف طلباته وحسابه بس. الأوردر المجمع (طلبات كل الناس) بيظهر لمسئول التوصيل بس.
- **مسئول التوصيل**: يقفل الأوردر ← ينسخ قايمة الطلب ← بعد الشراء يكتب الأسعار الفعلية ورسوم التوصيل ← يشوف حساب كل موظف (مترتب بالدور والمكتب) ← يعلّم «استلمت الفلوس». وفيه إدارة المنيو.
- **اقتراح يومي**: أول ما الموظف يفتح، التطبيق يسأله «تحب نفس طلب امبارح؟» بضغطة واحدة.
- **سجلّي**: تاريخ كل اللي طلبه + إجمالي الشهر + زر «اطلبه تاني».
- أي صنف جديد يكتبه موظف بيتضاف للمنيو تلقائياً (قسم «إضافات الزملاء»).
- سوبرماركت فيه قسم **سجاير** بالأنواع المعروفة في مصر (الأسعار تقريبية، عدّلها من إدارة المنيو).
- **جولات متعددة في اليوم**: مسئول التوصيل يقفل الجولة ويدوس «➕ جولة جديدة»، وكل جولة ليها حساب وأسعار ودفع لوحدها، وبتظهر منفصلة في سجلّ الموظف.
- **الإحصائيات** (لمسئول التوصيل): إجمالي المصروف، مصروف كل يوم، أكتر الأصناف، نوع العيش، أكتر الموظفين صرفاً، ومين لسه مادفعش.
- **صنف مش موجود**: مسئول التوصيل يدوس «🚫 مش موجود» على الصنف، وبعدها «💬 بلّغه واتساب» (رسالة جاهزة للموظف)، أو «🔁 بدّل» بصنف تاني، أو «🗑️ إلغاء». الصنف بيتشال من الحساب والريسيت والإحصائيات، والموظف بيشوف إنه مش موجود وممكن يلغيه.
- **سعر المنيو**: السعر الفعلي اللي مسئول التوصيل يحفظه (أو يتقرا من الريسيت) بيتحدّث بيه سعر الصنف في المنيو أوتوماتيك، فالأسعار الجاية تبقى دقيقة.
- **الريسيت**: مسئول التوصيل يرفع صورة الريسيت (أو أكتر) ← البرنامج يقرأ الأسعار ويحدّثها لوحده ويحسب حساب كل واحد، وينبّه لو فيه صنف مطلوب مش موجود في الريسيتات (ناقص).
- اليوم بيتجدد لوحده.

بعد أي تعديل في الكود لازم **Deploy ← Manage deployments ← New version**.
