# 🛵 هاتلى معاك

تطبيق ويب على Google Apps Script: الموظفين بيطلبوا فطار (فول وطعمية) وحاجات سوبرماركت، والسواق بيشوف الأوردر المجمع (كل صنف قدامه صاحبه) وبعد ما يجيبه بيشوف حساب كل واحد + الدور والمكتب.

## التركيب
1. افتح [script.google.com](https://script.google.com) ← **New project**.
2. انسخ `Code.gs` في ملف `Code.gs`، وأنشئ ملف HTML اسمه `index` وانسخ فيه `index.html`.
3. (اختياري) Project Settings ← Show `appsscript.json` ← انسخ محتوى `appsscript.json`.
4. **Deploy ← New deployment ← Web app**: Execute as *Me*، Who has access *Anyone*. ابعت اللينك للموظفين.
5. أول فتح بيعمل Google Sheet اسمها «هاتلى معاك - البيانات» أوتوماتيك (Users / Menu / Orders / Lines) ومعاها منيو جاهز.

## كود السواق
افتراضياً `1234`. غيّره من Project Settings ← Script properties ← `COURIER_PIN`.

## طريقة الاستخدام
- **الموظف**: يسجل اسمه والدور ورقم المكتب (مرة واحدة) ← يختار المحل والأصناف (أو صنف مكتوب بإيده) ← «ضيف للأوردر». يقدر يمسح طلبه طول ما الأوردر مفتوح.
- **تبويب الأوردر**: طلباتي + الأوردر المجمع (كل صنف وصحابه).
- **السواق**: يقفل الأوردر ← ينسخ قايمة الطلب ← بعد الشراء يكتب الأسعار الفعلية ورسوم التوصيل ← يشوف حساب كل موظف (مترتب بالدور والمكتب) ← يعلّم «استلمت الفلوس». وفيه إدارة المنيو.
- الأوردر بيتجدد كل يوم لوحده.

بعد أي تعديل في الكود لازم **Deploy ← Manage deployments ← New version**.
